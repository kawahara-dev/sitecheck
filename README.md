# sitecheck

公開前の Markdown と公開後のサイト内リンクを、1つの CLI でチェックするツールです。単一の Python ファイルで動き、標準ライブラリだけで動作します。

## 何ができるか

- **公開前（`pre`）**：ローカルの Markdown ファイルを検査し、見出し階層の飛び、空のリンク先、URL の体裁、空の画像代替テキストを行番号つきで報告します。
- **公開後（`post`）**：サイトマップまたはフィード（RSS／Atom）から記事 URL を取得し、各記事の内部リンク（同一ホストのみ）に到達できるか確認します。HTTP 404／410 は「リンク切れ」、タイムアウトや接続エラーなどそれ以外の失敗は「確認不能」として報告します。結果は Markdown または CSV で出力できます。

上記の検査と出力はすべて無料で使えます。

## 動作環境・インストール

- Python 3.10 以上（追加パッケージは不要です）
- `sitecheck.py` をダウンロードして、そのまま実行できます。

```sh
python3 sitecheck.py --help
```

## 使い方

### 公開前の Markdown を検査する

次の内容を `example.md` に保存します。

```markdown
# 公開ガイド

### 手順

[詳細]()
![](photo.png)
[サイト](https//example.com)
```

```sh
python3 sitecheck.py pre example.md
```

出力

```markdown
| 行 | 指摘 | 詳細 |
| --- | --- | --- |
| 3 | 見出し階層の飛び | H1 から H3 に進んでいます |
| 5 | リンク先が空 | 「詳細」のリンク先を入力してください |
| 6 | 画像の代替テキストが空（警告） | 画像の代替テキストを入力してください |
| 7 | URLの体裁 | 「https//example.com」: HTTP(S) URL のスキームを http:// または https:// と表記してください |
```

「警告」と付いた指摘は、レポートには表示されますが終了コードには影響しません。

### 公開後の内部リンクを検査する

```sh
python3 sitecheck.py post --sitemap https://example.com/sitemap.xml
python3 sitecheck.py post --feed https://example.com/feed.xml --format csv
```

出力（Markdown の場合）

```markdown
検査した記事 75件 ／ リンク切れ 0件 ／ 確認不能 0件

| 参照元 | リンク先 | 判定 | 詳細 |
| --- | --- | --- | --- |
```

問題のあるリンクだけが表に出力されます。CSV の場合、表が標準出力、集計が標準エラーに出力されます。

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 問題なし（警告のみの場合も含む） |
| 1 | 問題あり（`post` では確認不能も含む） |
| 2 | 引数・入力・出力エラー |

## 検査項目

| モード | 検査項目 | 判定の例 |
| --- | --- | --- |
| `pre` | 見出し階層の飛び | H1 の次の見出しが H3 |
| `pre` | 空のリンク先 | `[詳細]()` |
| `pre` | URL の体裁 | スキームの表記ゆれ、空白の混入、ホストなし |
| `pre` | 画像の空の代替テキスト（警告） | `![](photo.png)` |
| `post` | 内部リンクの到達状況 | HTTP 404／410 は「リンク切れ」、それ以外の失敗は「確認不能」 |

スキーム相対 URL（`//host/path`）は許容し、指摘しません。
